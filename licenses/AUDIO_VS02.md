# 首段试玩音频润色 v2

2026-10-11。三份新音源保存在 `assets/audio/vs02/`，旧 `assets/audio/vs01/` 音源保留；短动作音效仍使用旧版。

## 来源与制作

这三份 WAV 是本项目原创、可复现的程序合成音频，没有使用第三方录音、商业旋律、采样库或真实人物声音。钢琴主题是 **钢琴风格的合成音色**，不是实录钢琴：柔和击弦包络、带轻微非谐性的衰减泛音、轻微失谐双弦、低电平短房间反射。它的音色仍有合成乐器的局限。

`piano-quiet-theme.wav` 是 96 秒、十二个八秒乐句的原创轻力度旋律，音符稀疏，减少连奏与伴奏重复，保留呼吸和尾部安静空间。环境底各 24 秒，用固定种子的双重低通噪声和极轻低频共振模拟空气/房间氛围；不是实地环境录音，也不声称是鸟鸣、街声或人声。

格式均为单声道、44100 Hz、16 bit PCM。淡化尾部确保文件边界连续，游戏音乐保持连续播放；室内外环境先淡出再换源，暂停与恢复使用平滑增益。四组音量为零时直接暂停相应音频流，恢复时继续播放。

## 复现与验证

从项目根目录执行：

```powershell
node tools/audio/generate-vs02-audio.mjs --output test-output/polish-2026-10-11/audio/reproduced
node tools/audio/check-vs02-audio.mjs
```

生成脚本、固定种子、每份文件的来源、时长与 SHA-256 在同目录 `manifest.json`。检查覆盖两次生成哈希、PCM格式、峰值、波形步进、循环边界、音乐留白、环境底强度与高频粗糙度。数值检查不等于用户听感确认；最后仍需在游戏中试听，尤其确认合成钢琴的质感与轻环境底是否适合设备。

本项目可随游戏分发、修改和再生成这些原创素材；无外部音频授权依赖。
