# 借位解围后续出手对照

**结论**　看见「绕侧」时，先确认快拳手在做什么。前排已起手，要先应对预警。前排收招、后排仍远时，J 能省下耐力。上边缘路线里两人重新靠拢时，Q 才发挥出同时命中两人的价值。

## 控制条件

使用 `vs01-borrow-position-20261123` 的发行规则 DLL 与标签对应的战斗配置。第四波 `b2`，二级 110 经验，旧护手、日常外套、旧运动鞋。从默认出生点开始，每个条件使用种子 1–10，各配对跑一次 J 起手和一次 Q 起手，共 30 对。记录第一次出手的实际耗耐、有效伤害和承伤，招式结束或被打断后由相同的自适应策略接手。用时按完整战斗的运行帧计算，包含命中停顿。[收尾策略](../../scripts/Testing/CombatAutomation.cs) · [发行源码](https://github.com/anglelove3/gexingzhou-game/tree/vs01-borrow-position-20261123)

| 条件 | 两个方案共享的前置输入 | 出手时的局面 |
| --- | --- | --- |
| 开阔处 · 绕侧刚开始 | 按 D 20 帧，松开后等到看见绕侧且快拳手进入 J 范围 | 玩家在纵深 480，快拳手已起手 |
| 上边缘 · 绕侧刚开始 | 按 D＋W 140 帧，松开后使用同一出手判据 | 玩家在纵深 390，快拳手收招，游走手仍远 |
| 上边缘 · 两人重新靠拢 | 同上路线，按上一版原生实跑的配方，在松开移动后等 78 步 | 快拳手离玩家横向约 46 单位，游走手约 90 单位，出招期间还会靠近 |

第三个条件用来补看已知的双中窗口，保留前两组所有结果。每对的出手帧、坐标和出手前生命一致，两个起手都朝快拳手转身。
