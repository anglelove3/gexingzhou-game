# 葛行舟｜关卡总图与首段纵向切片

V0.2评审稿｜2026-10-03｜关联总案与数值设计

## 1. 空间组织

采用紧凑的分场景小地图，不在首版做连续大型开放世界。每个场景有不同构图与生活互动，连接地点用步行出口/车辆短过场；返回已访问地点无需长时间跑空街。

```text
现实层：安置小区门口 ─ 便利店/街边 ─ 粉丝汤店
                  └─ 家中 ─ 酒店
                  └─ 工业园保安亭 ─ 荒地 ─ 祭扫点

记忆层：粉丝汤桌/网吧清晨、清吧、大学琴房、旧村梦路
                  ↑ 由物件或手机进入，返回原现实场景
```

首段只开放门口、便利店、汤店和汤桌回忆；未开放出口用符合场景的围挡/改道表现，不摆放“未来城市传送门”。首段探索面积虽小，也提供两处可选观察和一次离开再返回，避免成为纯对话串。

## 2. VS01：可交付的一段完整游戏

目标：15—25分钟“回到现实关系”的体验。开始位置为小区门口，结束为粉丝汤回忆返回后张大炮约定伴郎安排。不是三日Demo的伪完成标记；首次菜单必须标示“首段试玩”。

| 节拍 | 玩家目标 | 必做 | 可选反馈 | 验收 |
| --- | --- | --- | --- | --- |
| 01 回乡 | 熟悉移动与观察 | 看见新小区及一句环境短语 | 路牌/围挡/旧手机 | 无互动也会收到语音 |
| 02 来电 | 处理或忽略邀请 | 张来见面、交喜糖 | 接听与不接不同吐槽 | 两路汇合且无重复物件 |
| 03 递喜糖 | 找到Hey | 靠近、递交 | 停留/收手机/离开 | 交互和任务完成可独立读档 |
| 04 去老店 | 进入汤店 | 与张碰面、坐下 | 旧招牌/装修/菜单 | 清楚下一地点，不靠全图搜寻 |
| 05 问这几年 | 用行动回应朋友 | 对话到少年旧事入口 | 吃、放筷子、看手机 | 每种动作有回应，无道德分 |
| 06 凑钢镚 | 操作少年回忆 | 推硬币到桌面 | 最后一块食物 | 全键盘可用，不改历史 |
| 07 回到现在 | 接住朋友的邀请 | 汤气返回、伴郎约定 | 谁扫码、收手机 | 保存终态并可继续/重看 |

### 稳定任务阶段

`free_arrival → invitation_pending → invitation_resolved → candy_hey_pending → candy_hey_delivered → soup_meet → memory_active → memory_returned → slice_complete`

阶段只向前推进，重看回忆不逆转任务。受邀由接听或张到场都到同一个终态；入口复用阶段条件；切场失败停留当前场景并保留任务，不提前标完成。

## 3. 小区门口：布局与开场分支

左到右逻辑位置暂定：旧路牌x=160、主角出生x=320、小区门口x=680、长椅x=960、车辆到达x=1320、场景出口x=1500。出生点左右各留至少96px安全空间，最初视野包含一个可交互物与右侧路口。

背景是统一搬迁后的楼群，前景旧门牌形成新旧反差。首段不摆亲属身份合照、墓碑或户籍，避免秘密在开场被泄露。

第一次操作提示只教移动；靠近路牌才教E；手机语音到达才教Tab。默认不整屏列按键。开场按第一项互动改变张的损友话术：看手机“手机还活着，人呢”；看旧牌“你搁这儿考古呢”；坐长椅“提前退休了”；无互动则“被绑架还是去美国了”。台词为本轮暂写，泰兴方言后续校对。

语音、来电与车到场间隔参见数值文档。接通电话仅形成约定，仍由车到场完成见面与喜糖交付；不接电话则车到场当面邀请。因此物件交付只在见面事件发生一次，来电不是喜糖生成点。

见面后张给出第一处地址，手机记录“把这份喜糖交给便利店门口的Hey哥，然后到粉丝汤店碰头”。地图出口明确显示目标；首段略过假面与李去，但不说“三份已经送完”，任务清单只承诺本段这一份。完整第一天再扩展多收件人配置。

## 4. 便利店：用人物教操作

主要对象：Hey、纸箱喜糖、门口饮料架、收银铃。远处先听“Hey”，没声音时仍有名字和环境提示。玩家按E进入交互，出现动作“把喜糖递过去”，执行才算交付；靠近/说话都不能自动扣物件。

交付完成后Hey才自然问“多久没唱歌了”。这里至少三种反馈：收起手机并停留，他玩笑后认真一句；继续看手机，他“我问嘴里，不是手机里”；转身离开，他把下一地点喊给你。用动作确认，不以玩家挂机秒数判心态。

剧情已完成时可以直接离开，无需穷尽所有对白。提前离开尚未交付则任务仍提示Hey持有待收糖；回来入口恢复。无法找到目标时手机显示地点词条而非亲属秘密。暂不展开Hey职业和情史。

## 5. 粉丝汤店：新店承载旧日

构图：左入口x=80、中桌x=440、右收银x=800；旧招牌在墙x=200，菜单x=700。老板无需新立绘，首段可用统一剪影灰盒与名字字幕，不暗示已有正式角色动画。

老板、旧招牌、套餐菜单各一个短段。对普通菜单阅读不做限时。现实价格不强行指定泰兴当前真实消费；菜单采用虚构价格或不出现金额，保留“变贵了/味道变了”的感觉。

坐下后张谈少年约定，再问“这些年怎么了”。主角三个动作可以回主线：继续吃后用玩笑接话、放筷子说“好像每条路都走过一点”、看手机掩饰后张夹肉。三路最终都进入同一个少年回忆，但回忆返回时的张有不同措辞。对话文字可修改，不冻结用户忘记的真实原话。

首段无点烟强制互动；如后续保留吸烟用于人物表现，不给予抽烟操作数值奖励。

## 6. 少年桌面回忆：最先验证的情感操作

进入条件：汤店对话已到少年旧事节点；返回上下文保存为`soup_shop`、原座位、对话返回节点、成年状态。现实与回忆采用不同标题“那年清晨”和不同物件，玩家不会误以为穿越改历史。

硬币初始4枚：三枚1单位、一枚2单位，凑5单位为场景叙事符号，不能当真实当年定价。操作是将硬币推/拖到桌中央区域；碰桌有音效与数量反馈。键盘左右切币，E推动；选择区域为固定安全区，不考鼠标精度。先不动作时有轻提示；退出回忆会回到汤店，入口保留，可以继续而不锁死。

最后一块食物提供伸手拿、推给张、暂时停下三种明确可结束动作；不是隐藏倒计时。出现损友台词与动作差异，仍保留二人后来凑钱吃完的历史事实。静态回忆物件可先使用几何图形，不能以“生图素材没齐”阻止首轮玩法验证。

返回汤气变薄，硬币声接扫码提示。付款短互动首段建议只用张/葛两种抢先动画，不做精确节奏比赛；某一方完成后立即禁用另一支付，避免双扣。现实旧手机支付不联接外部服务。

张最后说“明天伴郎，别再玩失联”，手机有一条后续安排。首段以桌上的两只空碗收束，提供继续探索本段、重看回忆、退出菜单；不得显示“已通关完整三日游戏”。

## 7. 完整第一天扩展

VS01通过测试后，喜糖路线扩成Hey→假面→李去/替换角色。假面在停车位被家里催相亲，会员与旧礼物暗示可错过；原故事没写完的李去不得用AI传记填充，可在公开版本推迟出现。

回家手机由玩家选择相册/录音/旧空间入口；普通内容轻量呈现，琴房和舞蹈是否制成可玩回忆另作内容评审。第一夜旧村地基与新楼叠层，空心人在远处随玩家接近后退；无血条、无追击失败，施工声接到现实来电进入第二天。

第一天不使用第二天三行动预算，避免在熟悉操作时错过重要关系。所有首段任务继续沿用原ID，不另建一套不兼容试玩任务。

## 8. 第二天关卡：承诺和陪伴的取舍

三项婚礼差事、送饭、留下处理、农活祭扫的预算详见数值。普通探索与物件观察不扣点；无感叹号不代表无提示，奶奶会在电话、现场工具和邻里话语中自然出现。

保安亭先呈现父亲工作、午饭盒、旧厂制服，职业境遇通过物件讲；往事未核实时不用定稿闪回。送完可以走，父亲与奶奶自己能处理。

留下处理冲突时“停手、谈、找奶奶、联系熟人”与动作路径均能汇合。现实战斗只在明确升级节点启用；不把工作人员画成无缘无故邪恶敌人。每路到奶奶叫停/谈妥收束，记录处理方式及父亲后续回应。“打赢地回来”是禁止结果。

亲戚半句“堂哥……”可由父亲打断，仅造成疑问；不能把这句自动转为玩家已知完整事实。后续农活→祭扫→旧合照为一次连续行动。祭扫称谓和三人合照组合形成足够证据；普通物件没有巨大箭头，仍须可辨认、可放大、按键查看文字，不能以看不清像素制造“可错过”。

晚上酒店统一集合，按未完成差事最多一个主动收尾。试音步骤：插接两端线材→试听→调整一个主音量→弹短曲；首版不制作专业多频段EQ模拟器。错误接口有形状/文字辅助，音量错误有视觉反馈，听力或静音设置不妨碍完成。张在门外听到未完成的歌，不让选项强迫他谈旧爱。

## 9. 第三天关卡：共同的生活

清晨：手机失灵、父亲准备衣服早餐、整理衣领与随礼。普通查看只感受到照顾；主动翻看背面/礼单才可能发现称谓异常。异常线索不可孤立变成“堂哥就是父亲”的全知旁白。

接亲：婚车短过场、堵门、婚鞋、生活问答。婚俗需要本地人校对；未核实的动作不宣称“泰兴必有”。新郎说关键答案，葛不能靠代答替他完成承诺。

婚鞋建议观察/聊天/交换/翻找＋收拾，但原第238题尚未明确选择。所有方案避免伤害、强迫和恶意羞辱现场人员。鞋的位置与至少两条有效提示预先固定，不随机到无法发现的位置；没有剩余筹码也能免费推进。

晚宴：停电→手机不能伴奏→原声吉他→朋友/父亲加入。纯吉他旋律未完成时先做可操作收尾灰盒，不使用商业歌曲。演唱不是准确击打音符的毕业考试；普通点击/按节拍有辅助，不能唱错就让所有人失望。未来计划由玩家明确选择，具体后日谈由证据变化。

## 10. 防卡死矩阵与验收

| 风险 | 预防/恢复 |
| --- | --- |
| 不接电话 | 张到场后统一见面事件 |
| 对话时走开 | 非关键对白允许结束；任务保持 |
| 离开Hey没交糖 | 入口可返回、物件不丢 |
| 推币顺序不同/重复推 | 完成按集合计算，不按顺序写死 |
| 回忆退出/读档 | 返回上下文显式保存；阶段不提前完成 |
| 路口在对话中触发 | 切场请求等待安全节点或取消，禁止双转场 |
| 任务事件重复 | 稳定ID幂等，奖励/扣物一次 |
| 点数耗完 | 仍可前往酒店；关键家事不生成第四点需求 |
| 没做婚礼差事 | 朋友补位、夜晚有限收尾，不婚礼失败 |
| 缺婚鞋提示筹码 | 免费观察/聊天路径 |
| 没发现身世 | 完整普通结尾，不兜底曝光 |
| 不愿战斗或调低动作难度 | 非战斗分支汇合，不失去主线 |
| 无声音/色觉差异 | 字幕、形状、标题、反馈同时成立 |

首段路径最少测试：接听/忽略各一轮；Hey交付前走开再回来；手机读到中途关；回忆中退出与重入；每种食物动作；每个安全检查点退出重载；键盘与鼠标分别完成。后续时间路径测试四种典型组合，确认已耗行动与结尾世界状态一致。

公开试玩前邀请不知道设定的人测读“张为何来、糖送谁、回忆从哪来、如何回现实”。他们不知道身世不是失败；他们不知道下一个可操作目标是可用性缺陷。
