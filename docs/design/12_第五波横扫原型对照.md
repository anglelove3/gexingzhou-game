# 第五波横扫原型对照

第五波「三 · 应对围攻」开放第四波的 Q 回身横扫。耗 30 耐力，前摇 12 个逻辑帧，冷却 1.5 秒。守势手正面对着玩家格挡时，K 蓄力破防仍是可选打法。横扫在第五波有效命中两人或三人都计一次「横扫多目标」，统计实际扣血。旧导出的 `AreaDoubleHits` 字段继续表示同一次横扫达到两次有效命中的次数。

## 自动配对

对照公开版 `vs01-opponent-labels-20261124` 与原型配置。使用同一规则程序，比较三级普通进度和五级满血单波连战夹具。两种夹具各用旧护手、轻拳套、练习短棍，搭配日常外套、旧运动鞋。每种武器各有三种接敌路线，从默认出生点直接由策略控制，或先向右上、右下移动 140 步。每组跑四种策略，共 72 局。五级夹具用于固定第五波的开场条件，完整生命继承及历史另跑六波连战回归。

- 公开版和原型各用同一个仓库 J/K 自适应策略，18 对逐项一致。
- 择机用 Q 的策略要求耐力与冷却允许，当前至少两人可有效受击，且未检测到更早会命中的在途攻击。其余时候沿用相同 J/K 策略。
- 冷却好就用 Q 的对照在角色可行动且耐力足够时尝试横扫。

时间含命中停顿，清场用时只统计胜局，承伤包括超时局。普通超时来自轻拳套下缘路线，达到 120 秒时仍在战斗。普通三条路线中，择机用 Q 的平均用时相对各自 J/K 对照，旧护手少 0.13 秒、轻拳套少 1.58 秒、短棍少 0.30 秒。短棍单次双目标伤害较高，轻拳套在这批整局样本中的用时收益最大。五级夹具的旧护手有增加用时的路线。策略使用可读的内部状态，真人是否找到相同时机待测。

## 命中与表现

三级默认装备受控场景中，空挥耗 30 耐力和冷却，范围伤害为 0。守势手正面格挡并与一名普通对手同进圈时，有效命中 1 人、实际范围伤害 17，累计 0 次多目标。守势手格挡且另两人都被打中时，有效命中 2 人、实际范围伤害 32。三人均有效命中时，分别扣 14、15、15 点，累计一次多目标、44 点实际范围伤害。三笔跳字按接触位置横向留出间距。初版原型三人贴近时，姓名和血条出现交叠。在当前候选中，三组名牌根据画面上的左右位置避让，留出 8 个场景单位的横向间隔。靠场边时整组向内放置，细线连回各自角色。守势和起手预警随其名牌移动，角色身上的动作提示位置保留。分散或只剩一人时，名牌回到角色正上方。

## 范围技候选版

早期对照中的 44 点为横扫初版基线。2026-11-27 验收的候选把 Q 的第五波伤害系数调为 1.08，并加入 E 踏地震步和 R 推掌开路。选择依据是出手时的敌人位置和状态。

| 招式 | 适用场面 | 耐力 | 前摇 | 冷却 | 三级默认装备的自然路线样本 |

模拟对照中，三级择机用 Q 的清场时间从 15.94 秒变为 15.78 秒，9 局均胜。这里的三招样本用于验证伤害、受击和推开，实战中的选招频率与长期平衡待真人复核。[本轮验收](../development/10_更新日志.md)

## 复现

在原型工作树根目录使用 PowerShell 7.4 或更高版本，先建立本地忽略目录，再用 Git 原始字节生成输入配置。

```powershell
New-Item -ItemType Directory -Force -Path test-output/wave5-study | Out-Null
git show d06b2a7:content/combat/combat.json > test-output/wave5-study/official.json
git show HEAD:content/combat/combat.json > test-output/wave5-study/candidate.json
dotnet run -c Release --project tests/Wave5SweepStudy -- test-output/wave5-study/official.json test-output/wave5-study/candidate.json test-output/wave5-study/comparison.json
```
