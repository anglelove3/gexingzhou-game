# 操作与素材

A/D或左右键移动，Shift加快；靠近金色目标按E。Tab打开/收起手机，Esc关闭当前界面；自由行动时Esc打开设置。↑↓/Tab切换选择，Enter或E确认。F5手动保存、F9读手动槽。回忆用左右/A/D选硬币，E推过；五个单位齐后明确选择食物，等待也必须确认。Esc可退出回忆，进度保留。

字体20—32，字幕可立即显示；减少动效把转场改为0.15秒。操作辅助只增加指引，不决定选择、不改写历史。当前没有背景音乐和语音，消息及台词都有中文文字；没有随机误触。

本地记录默认关闭。开启后只记录数值设计约定的七类事件、随机周目ID、递增序号、场景和选择代码；不会上传、不会记录姓名、账号、现实时间、机器ID或私人聊天。中途开启/关闭会留下不完整片段，应先检查数据质量，不能用于人格诊断。每次实际进入/返回通过visit序号配对；重看使用新回忆实例。清空记录不删除存档，导出只保留允许字段。

assets/manifest.json是已用素材台账。当前几何画面来自项目代码；系统中文字体只运行时查询，不复制分发。原六张人物概念图、故事集、ZIP和现实人物照片都没有用于正式导出。无需额外插件，也没有为了灰盒下载素材或生成无用图片。
