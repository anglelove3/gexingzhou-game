# 每次一个练习 · 游戏优先

第一个练习只看`code/Domain/MovementModel.cs`，不用急着改代码：从静止开始、一直向右、步行，单次dt=0.1秒时，速度会是多少？为什么不是立即到112？结合加速度800、上限112，尝试用自己的话解释。

回答后再一起做一次小改动并运行对应Movement测试。不要同时学习五种语言或先堆AI框架。你之前有策划、剧情、数值、美术与音乐经验；这次用一段真正能玩的作品学习C#变量/函数/集合、输入和状态机，再接存档与测试。

后续顺序暂定：首段真人试玩与节奏修改→原创美术/音乐与素材授权→扩大内容→用本地匿名测试事件学习SQL和数据质量→独立的Python/AI实验。当前事件只是小样本结构化记录，不是“大数据系统”；自动化测试的数据是人工脚本产生，不能拿它推断真实玩家习惯。AI实验先离线评估，未经讨论不接入正式剧情。

求职材料逐步积累可运行作品、设计总案、数值表、关卡图、状态/存档设计和测试报告。毕业时间与招聘目标后续再按实际日期确认，不把此前“明年6月”当永久固定日期，也不承诺1万元或双休岗位一定获得。

人物与家庭线索均保留修改空间；父母年轻时的爱情、生意及家庭经历需用户回访后补充。林知微有自己的生活，不是通关奖励；VS01不揭穿堂哥/堂嫂身份。新增台词与玩法一次只讨论一个问题，避免把推测当原资料。
