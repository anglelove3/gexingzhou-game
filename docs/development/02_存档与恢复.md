# 存档与恢复

自动检查点在见面、交糖、坐下、回忆动作和返回/结束时保存。F5保存手动槽；F9载入手动槽。手机和对白打开时也可手动保存，继续时恢复可操作状态，不从半句台词恢复。

新正式存档schema 2 / vs01-0.2位于Godot的user://saves/vs01-explore-v2（Windows用户应用数据目录）；不在项目源码中。旧user://saves/vs01的schema 1 / vs01-0.1文件只读。每槽保留上次有效备份。版本未知、截断或缺字段的存档会拒绝读取，并保留原文件；选择恢复备份或新游戏时先保留副本。不自动下载、上传或云同步。

新槽的主文件或备份只要存在（含损坏、未知版本或目录占位）就阻止旧槽迁移，绝不默默退回v1；自动/手动槽分开处理。只有对应新主档和备份都不存在，菜单才提供旧档或旧备份复制升级；先确认再写新槽，取消不写、旧字节不变。新偏好优先；无新偏好时才复制有效旧偏好，复制失败保留当前内存设置。

新档保存合法脚坐标和三处soup.sign/menu/note发现记录。汤店坐稳/动作保存合法站位，靠近就位中保存实际合法脚位置，不保存姿态。旧汤店横向坐标迁移到合法安全/回忆返回锚点。已占据家具的位置读档时使用安全落点；恢复通知暂未透传到新界面，属于已登记的轻微待办，不能声称已提示。未知坐标/版本不覆盖。F9/切场先准备和验证，失败保留当前世界/手机/坐姿与焦点，不把失败当成新游戏。

回忆中保存包含硬币、食物、回忆实例及返回汤店的位置。食物已确认但尚未返回时关闭程序，继续会完成返回，不要求重新付款或重做选择。

回忆里的F5保存回忆虚拟坐标，不用隐藏汤店的角色位置覆盖它，返回位置仍单独保存在ReturnContext。F9读档候选先校验真实汤店导航和回忆必需节点，成功后才清理当前会话。失败通过Main/Notice非阻塞通知，原手机焦点、当前对白完成回调和Flow保持不变。普通切场失败也显示原因，不静默吞掉错误。

Boot恢复菜单位于静态MenuScroll/Menu，大字号双槽错误时可以滚动阅读，键盘聚焦会自动带到对应按钮；旧槽复制升级行为不变。测试套件FinalBoundaries覆盖这些失败边界与坐下就位失焦暂停。

自动测试全部使用test-output子目录，不接触玩家的正式存档。文件事务与逻辑测试不代替实际关闭程序、重开继续的检查；后者列入试玩验收记录。
