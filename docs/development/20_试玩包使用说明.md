# 葛行舟 · 故乡与一碗热汤

VS01 战斗成长试玩 · 借位解围版｜2026-11-23（北京时间，UTC+8）

## 开始试玩

1. 把整个 ZIP 解压到一个普通可写文件夹，不要直接在压缩软件中运行。
2. 双击 gexingzhou-demo.exe，选择“回到故乡”。
3. 保持 EXE、PCK 和 data 开头的依赖目录在原来的相对位置；不要只复制 EXE。

主菜单“回到故乡”进入叙事首段，“战斗试玩 · 街头练习”进入独立战斗成长流程。战斗提供5级、9件装备和三段六波挑战，准备界面可换装并查看属性与连段测算。

这是 Windows x64 版，运行不需要 Godot 编辑器或 .NET SDK。包内附带的运行文件不要删除。Windows 若提示来源未知，请确认下载来自官方项目仓库并核对发行页 SHA256；不要为试玩关闭安全软件。

## 这段故事

回到搬迁后的故乡，接到老朋友的结婚邀请。帮他递一份喜糖，再去汤店坐一会儿。
流程包含小区、便利店街、汤店、硬币回忆和首段收尾，不是完整多日游戏。可以沿目标推进，也可以看看街上的小物件，不必找齐见闻。

建议为初次阅读和探索预留 10–15 分钟；这是安排建议，不是计时测量。没有探索倒计时，静音也能完成。

## 故事操作

- WASD / 方向键：走动；Shift：加快。
- 靠近人物、物件和路口，按 E 互动。
- 对白：E / Enter 继续；长文可滚动；Esc 收起。
- 选项：方向键选择，Enter 确认。
- Tab：手机；来电时 Enter 接听。
- J：今日记事；目标卡的 + 或记事“当前”页可看位置提示。
- 坐下后 Esc 起身；先收起界面并起身，Esc 打开暂停菜单。
- 暂停里的“操作与试玩提示”可反复查看。
- F5：手动保存；F9：读取手动档。暂停菜单可保存并退出。
- 回忆：拖币到桌对面，或左右键选币、E 推币。四枚硬币推完后再选怎样接过汤。Esc 可暂离，下次接着来。

## 存档与设置

### 战斗操作与进度

WASD / 方向键移动，J轻击，连续按可接三段。K按住约半秒后松开蓄力重击，快速按下松开为普通重击。L正面防御，Space闪避，Esc暂停。安全准备界面可用I定位装备列表，也可鼠标点击或Tab选择、Enter穿戴。

想试新连招，从主菜单进入「战斗试玩 · 街头练习」，选择第一波「一 · 拳脚对练」。贴近快拳手，对齐脚底，在上一拳出手时按下一次 J，就能连上快拳、转身拳和正踢。第二拳命中后，看到提示可按 K 改接低扫腿。低扫腿消耗24耐力，会让快拳手短暂倒地。第二拳空挥或被格挡时，继续用 J 接正踢。

接正踢时角色会立即抬膝，接低扫腿时会压低身体。可以观察这两个动作判断第二拳接成了哪种收尾。

第二拳快打到时，可以提前最多 4 个逻辑帧（约 67 毫秒）按 K。第二拳在这段时间内打出有效命中才会接扫腿，空挥或被格挡会清掉提前输入。

第一波右上角提示会提醒走位节奏。扫倒后先横移，快拳手再起手时继续走位。

到第四波「二 · 走位与节奏」，J 的有效命中有 10% 概率打出 1.5 倍伤害，金色数字会标明「暴击」。两人快靠拢时提前按 Q 回身横扫，留意对手起手。横扫消耗 30 耐力，冷却 1.5 秒，脚下椭圆显示有效范围。每个对手每次最多受到一次伤害，格挡仍会减伤。两人贴近时，横扫的两笔跳字按受击位置左右错开。同一次横扫有效打中两人时，脚边显示「横扫双中」，并叠加一层低沉的冲击声。结算可查看双中次数和实际范围伤害。

第四波可以用纵深移动让快拳手隔在你与游走手之间。游走手短暂停步后侧移，脚边显示「绕侧」。快拳手头顶出现「！起手」时，先应对来招。等快拳手收招，可按 J 打前排，或趁两人快靠拢时提前按 Q。

观察对手预警，蓄力重击可破开守势。领队受到两次有效重击会倒地。空耐力时可以走位等待恢复。每波开场恢复生命和耐力，每波完成后保存经验与装备，中途离开从本波开场重试。暂停清除待执行按键并取消未释放蓄力，恢复后重新按键继续操作。

轻击造成有效的非格挡伤害后，可在收招期间按Space闪避衔接，仍消耗24耐力并受闪避冷却限制。前摇、出招有效阶段、空挥、被格挡、重击或受击时不能这样取消。界面仅在耐力和冷却都允许时提示衔接。

轻击、三连末段、重击和蓄力的命中停顿、声音与短促冲击反馈分层。守势手有可辨识提示，观察后尽早蓄力。最后一击先保存结果，再短暂展示收尾并打开结算；保存失败会立即显示重试。减少动效会关闭镜头位移、闪变和飞散效果，保留伤害信息及声音。

### 装备流派与街头连战

- 轻拳套第三段造成有效的非格挡伤害后返还6耐力，每次出手最多返还一次。
- 练习短棍的蓄力重击正面命中防御姿态目标，伤害额外乘1.20；蓄力出招额外消耗4耐力。
- 旧护手在进入防御后的6个逻辑帧内成功正面格挡，会获得90帧反击机会，下一次发动的轻击第一段伤害乘1.25，空挥也消耗机会，触发冷却120帧。战斗固定60Hz步进，暂停冻结机会计时。
- 普通六波通关后解锁“街头连战”。开场确认5级和当前装备快照，六波期间生命逐波继承，耐力每波回满，波间点击继续进入下一波。失败或主动结束后可从第一波重新挑战。
- 挑战提供成绩和完成记录，普通成长经验与装备由原首次通关流程发放。旧通关档可直接进入连战。
- “连战记录”显示最近成绩及当前配置/装备最快六波时间，滚轮或PgUp/PgDn滚动，Esc或“返回准备”收起。历史文件持续保留，异常记录可从备份恢复。

连战记录位于 `saves/combat-v1/challenges-v1`，每次尝试使用独立文件及备份。保存失败时界面保留结果供重试，已经结束的尝试等待保存时暂停战斗。程序中途关闭后，本次尝试显示为中断，下次从第一波重新开始。其它窗口重开普通周目时，当前连战继续采用开场快照，返回准备后读取当前普通周目。

结算同时显示可操作时间、包含命中停顿的战斗总时间、计算伤害、实际扣除生命的有效伤害，以及回气、及时格挡、反击和破势统计。主动导出可保存该次结果，自动化测量与真人体验的条件见仓库数值报告。

战斗进度使用同一用户数据目录下的 `saves/combat-v1`，与故事进度各自保存。结算可主动导出本次统计，文件保存在战斗目录的exports子目录。保存失败会保留当前结算供重试。

多个窗口同时练习时，重开或恢复备份会建立新的周目标识。旧窗口结算会先把本次进度另存为战斗目录中的 `preserved-attempt-*.json`，再读取当前周目，界面会提示处理结果。另存失败可在结算界面重试。保留副本后若其它窗口更新了进度，需要重新保留副本后再操作。此前已发布的战斗存档可以继续读取。

### 故事存档与共用设置

存档在 Windows 当前用户的 AppData/Roaming/Godot/app_userdata/葛行舟｜首段试玩/saves/vs01-explore-v4 下，不在安装包里。开始新游戏会先保护已有进度；不要为了重开直接删除整个用户数据目录。

设置支持 20–32 字号、字幕速度、减少动效和分组音量。本地行为记录默认关闭；游戏不登录真实微信，也不向他人发消息。

“减少动效”开启时，菜单飘叶隐藏、背景居民停止移动；若想看秋叶和居民步态，可在设置中关闭该选项。
