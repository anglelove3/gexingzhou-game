# 葛行舟 · 故乡与一碗热汤

VS01 战斗成长试玩 · 存档修复版｜2026-11-13（北京时间，UTC+8）

## 开始试玩

1. 把整个 ZIP 解压到一个普通可写文件夹，不要直接在压缩软件中运行。
2. 双击 gexingzhou-demo.exe，选择“回到故乡”。
3. 保持 EXE、PCK 和 data 开头的依赖目录在原来的相对位置；不要只复制 EXE。

主菜单“回到故乡”进入叙事首段，“战斗试玩 · 街头练习”进入独立战斗成长流程。战斗提供5级、9件装备和三段六波挑战，准备界面可换装并查看属性与连段测算。

这是 Windows x64 版，运行不需要 Godot 编辑器或 .NET SDK。包内附带的运行文件不要删除。Windows 若提示来源未知，请确认下载来自官方项目仓库并核对发行页 SHA256；不要为试玩关闭安全软件。

## 这段故事

回到搬迁后的故乡，接到老朋友的结婚邀请。帮他递一份喜糖，再去汤店坐一会儿。
流程包含小区、便利店街、汤店、硬币回忆和首段收尾，不是完整多日游戏。可以沿目标推进，也可以看看街上的小物件，不必找齐见闻。

建议为初次阅读和探索预留 10–15 分钟；这是安排建议，不是计时测量。没有探索倒计时，静音也能完成。

## 故事操作

- WASD / 方向键：走动；Shift：加快。
- 靠近人物、物件和路口，按 E 互动。
- 对白：E / Enter 继续；长文可滚动；Esc 收起。
- 选项：方向键选择，Enter 确认。
- Tab：手机；来电时 Enter 接听。
- J：今日记事；目标卡的 + 或记事“当前”页可看位置提示。
- 坐下后 Esc 起身；先收起界面并起身，Esc 打开暂停菜单。
- 暂停里的“操作与试玩提示”可反复查看。
- F5：手动保存；F9：读取手动档。暂停菜单可保存并退出。
- 回忆：拖币到桌对面，或左右键选币、E 推币。四枚硬币推完后再选怎样接过汤。Esc 可暂离，下次接着来。

## 存档与设置

### 战斗操作与进度

WASD / 方向键移动，J轻击，连续按可接三段。K按住约半秒后松开蓄力重击，快速按下松开为普通重击。L正面防御，Space闪避，Esc暂停。安全准备界面可用I定位装备列表，也可鼠标点击或Tab选择、Enter穿戴。

观察对手预警，蓄力重击可破开守势。领队受到两次有效重击会倒地。空耐力时可以走位等待恢复。每波开场恢复生命和耐力，每波完成后保存经验与装备，中途离开从本波开场重试。暂停清除待执行按键并取消未释放蓄力，恢复后重新按键继续操作。

战斗进度使用同一用户数据目录下的 `saves/combat-v1`，与故事进度各自保存。结算可主动导出本次统计，文件保存在战斗目录的exports子目录。保存失败会保留当前结算供重试。

多个窗口同时练习时，重开或恢复备份会建立新的周目标识。旧窗口结算会先把本次进度另存为战斗目录中的 `preserved-attempt-*.json`，再读取当前周目，界面会提示处理结果。另存失败可在结算界面重试。保留副本后若其它窗口更新了进度，需要重新保留副本后再操作。此前已发布的战斗存档可以继续读取。

### 故事存档与共用设置

存档在 Windows 当前用户的 AppData/Roaming/Godot/app_userdata/葛行舟｜首段试玩/saves/vs01-explore-v4 下，不在安装包里。开始新游戏会先保护已有进度；不要为了重开直接删除整个用户数据目录。

设置支持 20–32 字号、字幕速度、减少动效和分组音量。本地行为记录默认关闭；游戏不登录真实微信，也不向他人发消息。

“减少动效”开启时，菜单飘叶隐藏、背景居民停止移动；若想看秋叶和居民步态，可在设置中关闭该选项。
