# 第四波无讲解试玩

观察首次接触《葛行舟》的玩家能否仅凭游戏内提示，在普通第四波「二 · 走位与节奏」打出第一次 Q 双中。使用 `vs01-opponent-labels-20261124`，每位玩家从二级默认装备进度开始，前三波已完成，第四波已解锁。本页供主持人使用。[Windows 发行版](https://github.com/anglelove3/gexingzhou-game/releases/tag/vs01-opponent-labels-20261124)

## 开场

1. 在项目根目录运行 `./tools/new-wave4-playtest.ps1`。工具校验发行 ZIP，并在 `builds/` 下准备一份新的副本。ZIP 放在其他位置时，传入 `-ZipPath "Windows ZIP 的完整路径"`。每位玩家使用新的副本。
2. 打开输出的 `playtest.cmd`，从主菜单点「战斗试玩 · 街头练习」，停在第四波准备页。确认二级、110 经验和三件默认装备。进入此页即开始计时。
3. 对玩家说「请用当前装备试打这一波，按你看到的提示操作。每局结算时请先停一下。」主持人保留本页和包内的《开始试玩》，完成试玩后再讨论操作。
4. 最多观察 8 分钟或 3 次完整结算，以先到者为准。每次结算点击「导出本次战斗统计」，按顺序在本地记录文件名，再让玩家重试。到达时限时仍在战斗的局次记为中断。

## 结束后提问

- 你先注意到了哪些提示？它们有没有让你改变动作？
- 你怎么判断刚才的一招打中了几个对手？
- 如果再试一次，你会在哪个时机出手？

先看玩家有没有发现出招，再看会不会等两人靠拢，最后看命中后能不能辨认结果。若全程没发动，先检查准备页与战斗内提示能否让人找到 Q。若发动多次仍未双中，对照出手时的站位、对手预警和有效帧。若双中却没有被察觉，回看跳字、双中提示和声音。首轮可从 3 到 5 位首次试玩者开始，用来定位卡点。
