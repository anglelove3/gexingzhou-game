# VS01运行与测试

打开本项目的project.godot，使用Godot 4.7.2 .NET版，按F5运行。VS Code打开整个项目目录，终端运行`dotnet build GeXingzhou.csproj`。必须.NET版本，普通Godot不能执行C#。

规则测试：项目根目录运行`dotnet run --project tests/DomainChecks`；`-- --filter Content`可筛选一组。退出0通过、1失败、2没有匹配测试。测试输出不是可运行包证明。

当前首段已使用正式AI栅格美术，汤店是Depth2D探索样板，不是完整三日游戏、严格手工像素终稿或独立EXE。角色与故事私人原资料不移入运行资源，不上传公开仓库。
