# 战斗打击感与操作衔接设计

北京时间 2026-11-18。用户已确认上一轮提出的“打击反馈＋有限战斗规则精修”，本稿记录实施初值，由协作者提出，真人手感仍待用户试玩。

目标：在现有横向街头战斗中展示招式节奏、攻防判断及可解释的数值取舍，服务 ACT/ARPG 策划作品展示。保持原故事、美术风格、5级/9装备/六波、schema4故事档与combat-v1旧进度；不增加章节或另建项目。

比较方案：只加视听效果，风险较小但无法解决破势机会和操作衔接；用户选择反馈与规则一起精修。大规模扩充技能、敌人与地图不在本轮范围。

## 实施初值

- 固定60Hz。轻击一/二/三、重击、蓄力命中停顿分别2/3/4/5/7帧；格挡反馈最长2帧，敌人轻/重命中仍2/4帧。空挥不产生命中反馈。
- 轻击对敌人造成有效非格挡伤害后，当前攻击进入后摇满4帧起可用闪避取消。沿用24耐力、39帧冷却和原有无敌帧，不新增无敌或返还攻击耐力。空挥、格挡、前摇、有效帧、重击、受击均不可取消；按键仍使用现有6帧缓冲。换招清除命中确认。
- 守势手持续防御48→72帧，加入可辨识守势提示；短棍蓄力27帧加19帧前摇，给近距离观察后反应留出约0.4秒，实际边界用逐帧测试核实。额外4耐力与×1.20收益保持。
- 定向短促冲击图形、受击局部变色、身体偏移回正、轻微场景位移和命中音高/音层区分。复用现有图集和授权音源，Godot原生绘制，不生成新人物。逻辑击退总量和判定坐标保持，显示层把瞬间位移平滑展开，HUD不随镜头震动。
- 减少动效关闭镜头位移、受击闪变与飞散效果，保留稳定伤害/格挡信息和音效。暂停、设置、失焦冻结效果；切换波次清除旧反馈。
- 最后一击保留0.32秒收尾（减少动效0.18秒），立即保存普通奖励或连战结果，延迟的只是结算界面。保存失败立即显示重试界面；关闭程序也不丢已成功保存的奖励。
- balanceVersion升为combat-impact-0.1。历史配置缺省值保持旧行为，配置哈希隔离最快成绩；旧挑战历史保留。新增取消次数统计缺省0。

## 验证与交付

规则红绿测试：命中停顿/缓冲、取消边界/成本/空挥及格挡拒绝、守势反应延迟边界、旧配置兼容。引擎：真实按键、普通/连战结算即时落盘与延迟显示、失败保存、暂停/失焦/减少动效。GPU实渲染检查分层效果和最大字号。回归故事、旧存档、实际发行PCK与冷解压EXE。

记录调整前后条件相同的自动化数据，不能把自动策略胜率或截图当作真人手感结论。完整Windows包和源码同步GitHub；旧Release先备份校验再撤下。用户本地project.godot不覆盖、不提交、不用于发行。
