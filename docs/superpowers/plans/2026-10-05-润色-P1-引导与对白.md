# P1 引导与逐句对白 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R1/R4：缩短首次等待、提示真实目标，逐句区分讲话、心声和旁白。

**Architecture:** ContentCatalog验证可选逐句元数据，DialogueSession只提供当前行。引导提示是会话表现，不发奖励事件。

**Tech Stack:** Godot.NET/C#、既有JSON、DomainChecks、SmokeHarness。

**Spec:** E:/游戏创作/顾行舟/docs/superpowers/specs/2026-10-05-首段玩家体验润色-design.md，§3、§6。

## Global Constraints

继承实施入口全部约束；首次语音8秒，来电15秒、到场30秒；保留旧DialogueNode构造及事件ID，不把行序号存档。
