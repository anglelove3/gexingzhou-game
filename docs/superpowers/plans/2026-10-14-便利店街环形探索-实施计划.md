# 便利店街环形探索 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有横向便利店街升级为不阻塞主线的纯室外四向环形街区，加入七处可选见闻、两位无名居民、轻环境声，并通过独立 v4 存档复制升级安全承接旧进度。

**Architecture:** 先把当前 v3 导航冻结成只读协议，再用纯领域层完成 v1/v2/v3→v4 复制升级；随后以静态 `.tscn` 和导航导出实现街区，复用现有 Depth2D、观察、日志与音频组件，仅补齐便利店街所需边界。最后执行全量自动验收、真实渲染矩阵、冷目录源码包验证和普通 GitHub 推送。

**Tech Stack:** Godot 4.7.2 .NET、C#/.NET 8、PowerShell 7、DomainChecks、Godot SmokeHarness、现有 imagegen 与可重复音频生成脚本。

**Spec:** `docs/superpowers/specs/2026-10-14-便利店街环形探索-design.md`（2026-10-14 用户回复“认可”批准；规格提交 `8e29946`）。

## Global Constraints

- 工程根固定为 `D:/游戏创作/顾行舟`；不读取、修改或打包真实 `user://` 存档、私人故事原稿、真人照片、本机配置及其他游戏资料。
- 本轮只升级 `convenience_street`；小区、汤店、手机、回忆、长椅和主线剧情不重新设计。
- 世界尺寸 `1600×720`；`entry=(100,520)`、`safe=(240,520)`、Hey哥 `(800,500)`、`exit=(1500,520)`；主街必须从入口直达Hey哥和汤店出口。
- 北环连接 `X≈380/1220`、上沿 `Y≈220`；南环连接 `X≈620/1000`、下沿 `Y≈650`；东支路只提供短距离往返。
- 七个新发现 ID 逐字使用 `street.doorplate`、`street.newsstand`、`street.bike_shed`、`street.drain`、`street.wall_paint`、`street.laundry_rack`、`street.stool`；运行时共十三个发现，固定顺序为小区三项→便利店街七项→汤店三项。
- 不增加室内、自动寻路、人物身世、可互动居民、奖励、支线、收集总数、Buff、隐藏结局、背包、经济、战斗、AI对话或联网功能。
- 新协议固定为 `schema_version=4`、`content_version=vs01-0.4`、`user://saves/vs01-explore-v4`；当前 v3 导航原字节冻结到 `content/vs01/compat/navigation-v3.json`。
- v4任一主/备槽存在即阻止静默回退v3；v3任一槽存在即阻止越过它猜测v2/v1；自动档与手动档分别处理，原档、备份、偏好与哈希不变。
- 合法 v3 便利店位置先由冻结 v3 导航验证，再映射为 `(原X,520)`；若新地图占位则回到 v4 `safe` 并提示。未知版本、未知/重复ID、重复字段、非有限或越界坐标一律拒绝。
- 场景主要布局、碰撞、锚点、热点及人物站位均静态写入 `.tscn`；导航未导出、节点缺失、ID重复或目标不可达时拒绝进入，不运行时兜底拼图。
- 正式资源必须记录生成提示、来源、许可和 SHA256；不以色块或临时占位冒充完成，不上传测试输出或私密文件。
- 每项任务执行“失败断言→确认红灯→最小实现→确认绿灯→精确提交”；不用编译失败、未知套件或资源未导入替代行为红灯。
- 整轮成为可运行更新且全量验证通过后，按北京时间更新说明、README、更新日志与验收接续文档，再普通推送 `origin/feature/vs01` 并核对远端 SHA；不强推。

## Review Focus

1. v4主档缺失但v4备份存在、同时v3主档有效时，不得自动读取v3；Task 1 的 `V4BackupBlocksV3Main` 固定槽位优先级。
2. v3便利店位置结构合法但映射后恰被新家具挡住时，只能回到同场景 `safe`，不能接受阻挡点或误判越界；Task 1 的 `StreetBlockedMappingUsesSafe` 固定边界。
3. 玩家在观察或暂停期间失焦、再切换“减少动效”，两位居民不能偷偷前进、瞬移或恢复旧回调；Task 4 的 `ResidentModalFocusReducedFreeze` 固定生命周期。
4. 透明像素覆盖热点、前景实心像素遮挡热点、UI盖住热点时，鼠标命中必须分别放行/阻止/阻止；Task 3 的 `StreetPointerOcclusionMatrix` 固定点击边界。
5. 汤店出口加载或导航预检失败时，当前街区、玩家位置、任务状态和存档文件必须保持不变；Task 2 的 `StreetExitFailureIsAtomic` 固定失败原子性。
