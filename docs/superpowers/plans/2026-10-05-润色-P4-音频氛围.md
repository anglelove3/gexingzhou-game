# P4 音频氛围 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R5：接入可追溯的原创拨弦动机、动作音效和环境底声，静音可独立玩。

**Architecture:** 每个Boot/Main根场景各一个AudioDirector，随根释放。音乐/环境专用播放器，短音效8槽；设置字段兼容旧文件。

**Tech Stack:** Godot AudioStreamPlayer/C#、项目内Node脚本离线生成PCM WAV；无外部运行依赖。

**Spec:** E:/游戏创作/顾行舟/docs/superpowers/specs/2026-10-05-首段玩家体验润色-design.md，§7。

## Global Constraints

继承入口约束；默认总音量0.8、音乐0.4、音效0.7、环境0.35；范围0—1；短音效池上限8；明确合成拨弦并非真实吉他录音，拒绝商业歌曲与声音克隆。

## Review Focus

旧设置无新字段；NaN/无穷；连续脚步/电话提示；切场景残留；音频缺失。任务1/2均有专门断言，试听另行记录。

### Task 1：可调音量与具名播放器

**Files:** Modify: code/Domain/GameSettings.cs、tests/DomainChecks/Checks/SettingsEventChecks.cs、scripts/SettingsController.cs、scenes/ui/Settings.tscn；Create: scripts/AudioDirector.cs、scenes/audio/AudioDirector.tscn；Modify: scenes/Boot.tscn、Main.tscn、scripts/Testing/SmokeHarness.Experience.cs、SmokeHarness.cs、tools/verify.ps1。

**Interfaces:** Settings新增double MasterVolume、MusicVolume、EffectsVolume、EnvironmentVolume；Normalize先用非有限值对应默认，再Clamp(0,1)。新增`enum AudioCue { Footstep,PhoneMessage,PhoneRing,Bowl,Chopsticks,Coin,Candy }`；Director `ApplySettings(GameSettings options):void`、`SetScene(string sceneId):void`、`PlayCue(AudioCue cue):bool`、`SetPaused(bool value):void`、`StopTransient():void`。MainView/BootMenu新增只读`AudioDirector Audio`绑定各自Audio节点。PlayCue返回实际启动与否，仅供表现检查，业务不得按此结果决定任务进度。

- [ ] **Step 1：写检查。** Settings组新增AudioDefaultsLegacy、AudioNormalize：旧JSON{}得到四默认值；-1→0、2→1、NaN/±Infinity→各默认；保存加载音量不丢。引擎ExperienceAudioChecks()：总音量0所有播放器实际有效增益0；连发20个音效活跃数不超过8；SetScene停止上一环境；根释放后无AudioDirector遗留；SetPaused时环境/音乐增益为正常的0.35且无脚步，恢复后原音量；这是本实现选定的暂停衰减值。

```csharp
Check.Equal(.8, new GameSettings().MasterVolume);
Check.Equal(0d, (new GameSettings { EffectsVolume=-1 }).Normalize().EffectsVolume);
Check.Equal(.4, (new GameSettings { MusicVolume=double.NaN }).Normalize().MusicVolume);
```

- [ ] **Step 2：运行红检查。** Settings域组及ExperienceAudio（注册后）；预期新字段缺失、播放器不具名、池无界检查失败。
- [ ] **Step 3：实现。** AudioDirector.tscn具名Music、Ambience、Effects/Slot1—Slot8；滑块在Godot场景编辑。增益=总音量×分组音量×暂停系数，0用静音而非log(0)。ApplySettings立即影响已播放声音。缺资源一次诊断后静音降级，别把绑定错误当音源缺失。播放器循环由单个Director管理。
- [ ] **Step 4：验证。** Settings组、ExperienceAudio、Accessibility、EditableUi通过；设置窗口滚动与焦点不回归；本步资源尚未完成时仅声明播放器行为验证，不声称音乐完成。
- [ ] **Step 5：提交。** `feat: 增加兼容旧设置的音量与音频模块`。

### Task 2：原创音源与业务接线

**Files:** Create: tools/audio/generate-vs01-audio.mjs、assets/audio/vs01/manifest.json、licenses/AUDIO_VS01.md及WAV文件；Modify: assets/manifest.json、AudioDirector.tscn、scripts/PlayerController.cs、MainView.cs、PhoneController.cs、SoupSeatController.cs、SoupMemoryController.cs、SceneFlow.cs、BootMenu.cs；Test: SmokeHarness.Experience.cs。

**Interfaces:** 离线脚本`node tools/audio/generate-vs01-audio.mjs --output assets/audio/vs01`，44100Hz/16-bit mono PCM，固定种子20261005，输出guitar-theme、footstep、phone-message、phone-ring、bowl、chopsticks、coin、candy、ambience-outdoor、ambience-indoor.wav。manifest逐项列脚本、种子、采样率、时长、哈希和原创合成来源；依前任务的AudioCue/Director接口接线。

- [ ] **Step 1：先写检查。** ExperienceAudio检查manifest每个文件可加载、WAV参数正确、重复生成哈希一致、非空且峰值≤0.95；通过调用路径验证静止无脚步、移动按累计步距32世界单位触发；两次Refresh同一来电状态只触发一次提示；动作重复提交不叠成功音效；缺一个音源时游戏仍可完成。
- [ ] **Step 2：运行红检查。** ExperienceAudio应资源缺失失败；源文件命名错误/缺manifest不可跳过断言。
- [ ] **Step 3：实现并生成。** 用固定种子的拨弦衰减合成短循环动机，现实和回忆由Director调整同源音色/留白；不是纯正弦报警声冒充正式配乐。原创噪声包络做短音效与轻环境底声，控制峰值。没有外部录音则不伪造鸟声/人声；听感不合格继续调整同源参数，不改许可描述。脚本是资源生成而非日常启动依赖。
- [ ] **Step 4：接入。** 业务仅在真实移动、消息状态变化、动作确定反馈和成功推币时发送Cue；SceneFlow结束后SetScene，释放/读档StopTransient。暂停接线由P5调用SetPaused。Boot与Main交接释放旧Director，不重复常驻。
- [ ] **Step 5：验证与试听。** ExperienceAudio、Invitation、Soup、Memory、ResumeSeed/ResumeRead全过；完整路径静音可玩；正常及耳机试听音乐循环、手机、碗筷、硬币和转场；记录哪些音源实际试听，不把headless静音运行当听感验收。无商业歌曲、无外网运行请求。
- [ ] **Step 6：提交。** `feat: 接入原创拨弦与生活声音`，只提交正式音源/脚本/来源和接线。
