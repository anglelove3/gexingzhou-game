# P3 桌面硬币 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R3：露出回忆桌面，让推币与碗靠近可见，鼠标和键盘均可完成。

**Architecture:** MemorySession继续作为进度权威；CoinDragPolicy验证方向/区域，控制器只把已提交ID映射到固定落点。不保存鼠标或Tween。

**Tech Stack:** Godot.NET/C#、现有coin-1/coin-2/soup-bowl正式资源、Control输入与Tween。

**Spec:** E:/游戏创作/顾行舟/docs/superpowers/specs/2026-10-05-首段玩家体验润色-design.md，§5。

## Global Constraints

继承入口约束；c1/c2/c3权重1，c4权重2，共5；无超时或善恶评分；三种现实反馈保持；静音/减少动效仍能玩。

## Review Focus

侧向/反向远拖不交付；光标离开控件仍能释放；重复提交不播放成功；重入按ID恢复；已完成重放不改历史。任务断言覆盖这些情况。
