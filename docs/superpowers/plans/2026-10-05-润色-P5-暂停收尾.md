# P5 暂停收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R6：玩家能暂停、保存、回菜单，试玩有克制的正式结尾，失败不丢档。

**Architecture:** 独立Pause/SliceEnd场景控制器，Main处理输入优先级；GameSession返回SaveResult，Repository继续负责原有保护。完成卡是表现，不发第二个任务事件。

**Tech Stack:** Godot.NET/C#、现有SaveRepository、FlowState和具名UI。

**Spec:** E:/游戏创作/顾行舟/docs/superpowers/specs/2026-10-05-首段玩家体验润色-design.md，§8、§10—11。

## Global Constraints

继承入口约束；仅自由活动且无汤店/长椅活动时打开暂停，既有Esc关闭语义优先；保存失败不切菜单/不退出；不保存Paused状态；完成文案“今天先到这里。明天见。”。

## Review Focus

磁盘写入失败/未知版本不绕过保护；Esc一键不连续关闭两个界面；设置恢复Pause；完成档不重复发事件；重开前保留旧档。任务1/2测试各钉住这些情况。
