# 今日记事任务日志 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans按任务执行；沿用用户此前已选Native本会话直接实施方式，不为本项目重新选择执行方式。Steps use checkbox (`- [ ]`) syntax for tracking. 计划须先经用户审阅确认，不能提前修改运行代码。

**Goal:** 在既有首段中加入J/HUD打开的“今日记事”，只读显示当前目标、真实已完成经历和已发现见闻。

**Architecture:** JournalProjection从WorldSnapshot投影只读结果，不成为第二个任务状态仓库。JournalController绑定预存Godot场景；MainView拥有输入入口、互斥与恢复规则。保持QuestReducer、存档格式和导航行为不变。

**Tech Stack:** Godot 4.7.2 .NET、C#/.NET 8、VS Code、现有DomainChecks与Godot SmokeHarness、PowerShell工具。

**Spec:** E:/游戏创作/顾行舟/docs/superpowers/specs/2026-10-10-今日记事任务日志-design.md（用户于2026-10-10回复“认可”批准）。

## Global Constraints

- 所有工程文件、测试产物和打包副本留在E:/游戏创作/顾行舟；不碰另一游戏、真实玩家存档或私人资料。
- 保持schema 2 / vs01-0.2和vs01-explore-v2；旧schema 1只走既有明确升级入口，不新增存档字段、发现ID或奖励。
- J/HUD打开，J/Esc/关闭按钮收起；仅稳定Field且无坐姿、回忆、对白、其它界面或切场时开放。日志内F5/F9不保存或载入。
- 已知见闻只限soup.sign、soup.menu、soup.note，不展示未发现项、收集总数或未来剧情；首次回忆事实只认soup-1。
- 浅暖纸色、深色文字、细边框；静态节点保存.tscn；正文20/24/32字号，面板宽最多900、高最多720、窗口安全边距24，不缩字号裁字。
- 三尺寸1280×720、1920×1080、1440×1080；长文滚轮、PgUp/PgDn、Home/End，Tab只在日志内循环。
- AudioDirector.SetPaused(true)停止瞬态音效并将音乐/环境声音量乘0.35；关闭恢复设置音量，不重启音乐或重播来电。
- 最终完成后普通推送原仓库feature/vs01并验证远端SHA；不强推、不建PR，不把设计/计划提交当成功能完成。
